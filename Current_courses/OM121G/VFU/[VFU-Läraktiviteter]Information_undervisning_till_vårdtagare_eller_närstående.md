Kursens lärandemål kopplat till läraktiviteten

    Kommunicera, bemöta, informera och undervisa vårdtagare och närstående utifrån ett personcentrerat förhållningssätt.
    Hantera läkemedel på ett patientsäkert sätt och kunna informera om läkemedelseffekter och biverkningar för vanligt förekommande läkemedel hos äldre. 
Förberedelser

Läkemedelsinventering (självständigt moment, se exempel längst ner):

Studenten gör en lista över 5–10 vanligt förekommande läkemedel hos äldre personer på aktuell verksamhet (ex läkemedel mot högt blodtryck, antikoagulantia, analgetika, diuretika etc). Läs på i FASS och andra relevanta källor för varje läkemedel och notera kort följande delar:

    Läkemedel
    Indikation
    Verkningsmekanism
    Vanliga biverkningar
    Viktiga patientråd/särskilda övervägande vid exempelvis hög ålder/samsjuklighet

Studenten väljer därefter i samråd med handledare ut ett (1) läkemedel att fokusera extra på. Det kan vara ett av vårdtagarens ordinarie läkemedel, vid behovs medicinering alternativt ett nyinsatt läkemedel. Studenten förbereder ett kort undervisningsmoment på cirka 5-10 minuter kring valt läkemedel.

Genomförande

Studenten genomför ett undervisande samtal med vårdtagaren och/eller närstående alternativt i ett simulerat scenario med fokus på valt läkemedel. Handledaren kan ge stöd vid behov, men håller sig om möjligt i bakgrunden och observerar och ger återkoppling efteråt.

Målet är att:

    Förklara syftet med läkemedlet, dess verkan och vanliga biverkningar på begriplig nivå
    Säkerställa förståelse genom exempelvis teach-back, aktivt lyssnande och öppna frågor
    Använda ett personcentrerat förhållningssätt
    Kommunicera tydligt och patientsäkert inom ramen för sjuksköterskans ansvarsområde
    Ge möjlighet till frågor/reflektion från vårdtagare/närstående

Efter genomförandet

Studenten reflekterar tillsammans med handledaren. Följande frågeställningar kan ligga till grund för reflektionen:

- Hur upplevde studenten kommunikationen med vårdtagare/närstående? 
- Vad utfördes bra och finns det delar studenten kan utveckla?
- Vad upplevde studenten som utmanande i genomförandet?
- Hur gjorde studenten för att informationen skulle bli personcentrerad?
- Följde studenten upp att vårdtagare/närstående förstått informationen? På vilket sätt?
